ABSTRACT

The purpose of this project was to develop a Driving School Management System that improves the management of driving school activities and records. Many driving schools experience challenges when using manual systems, such as difficulties in registering students, scheduling driving lessons, managing instructor records, tracking payments, and preparing reports.

The developed system provides a computerized platform that allows driving school administrators to register students, manage instructor information, schedule driving lessons, record payments, monitor student progress, and generate reports efficiently. The completed system provides an affordable, user-friendly, and reliable solution that supports effective driving school management and better decision-making.

2.2 Theoretical review

2.2.1 Systems Theory

The study is guided by Systems Theory, which explains that an organization or system consists of different interconnected components that work together to achieve a common goal. (Bayat, 2023)explain that systems thinking helps organizations understand the interdependencies, interconnections, and relationships between different elements within a system. Similarly, (Tackle, 2024)explain that systems theory provides a way of understanding organizations by considering the relationships between their different components and the wider environment.

In a driving school, activities such as student registration, instructor management, lesson scheduling, fee payment, student progress tracking, and report generation are interconnected. An Online Driving School Management System integrates these activities into one computerized system. Information from one activity can be used by another activity, making coordination between different functions important. The integration of these activities can improve communication, minimize errors, increase efficiency, and support better decision-making. Therefore, Systems Theory is relevant to this study because it views AA Driving School, Mombasa as a complete system whose different components and activities need to work together effectively (Bayat, 2023; Bayat, 2023)&, 2023; (Tackle, 2024)

2.2.2 Technology Acceptance Model (TAM)

The Technology Acceptance Model (TAM) explains how users accept and use new information systems. The model emphasizes two important factors: perceived usefulness and perceived ease of use. Perceived usefulness refers to the extent to which a person believes that using a system will improve their performance, while perceived ease of use refers to the extent to which a person believes that using the system will require little effort. Recent studies continue to support the importance of these factors in technology adoption. (R.Hanani, 2025)found that perceived usefulness and perceived ease of use significantly influence users' intention to use digital applications. Similarly, (Alberto Ortiz-Lopez, 2024)examined technology acceptance in an educational context and found that perceived usefulness is an important factor in users' acceptance and use of digital technologies.

In this study, administrators, instructors, and students will use the Online Driving School Management System. If the system is simple to operate and helps users complete their tasks faster, they are more likely to adopt it. Therefore, the system should have a user-friendly interface, simple navigation, and reliable performance. The perceived usefulness and ease of use of the proposed system will be important in encouraging users at AA Driving School, Mombasa to accept and use the system effectively ( (R.Hanani, 2025) (Alberto Ortiz-Lopez, 2024))

2.2.3 Information Systems Success Model

The DeLone and McLean Information Systems Success Model explains how the success of an information system can be evaluated using factors such as system quality, information quality, service quality, system use, user satisfaction, and net benefits. Recent research continues to demonstrate the usefulness of the model in evaluating different types of information systems. (A.A.Alhitty, 2023)applied the model to online learning and emphasized the importance of system, information, and service quality in determining system success. Similarly, (Tutut Widyaningrum, 2024)used the model to examine user satisfaction with a learning management system. (Saba, 2025)further highlighted that the core dimensions of the DeLone and McLean model remain relevant for evaluating information system effectiveness in modern technological environments.

For the Online Driving School Management System, the system should provide accurate information, operate reliably, be secure, and meet users' needs. The system should also provide quality services and satisfy administrators, instructors, and students. When these factors are achieved, users are more likely to use the system effectively, while the organization can benefit through improved service delivery, faster information retrieval, reduced paperwork, and efficient management ( (A.A.Alhitty, 2023); (Tutut Widyaningrum, 2024)24; (Saba, 2025)

3.6 System Development Methodology (Rapid Application Development Model)

This study adopted the Rapid Application Development (RAD) Model. RAD is a systems development approach that emphasizes rapid prototyping, user involvement, and continuous improvement during system development (E.Kendall, 2019)). The approach allows developers to create prototypes, obtain user feedback, and make improvements before the final system is implemented. RAD also supports an iterative development process in which system requirements and designs can be reviewed and refined throughout the development process (Rosenblatt, 2019)The RAD model was suitable for this study because it allowed the researcher to develop the proposed Online Driving School Management System in stages. It also provided an opportunity to identify problems, make improvements, and ensure that the system addressed the requirements of AA Driving School. The RAD model used in this study consisted of four main phases: Requirements Planning, User Design, Construction, and Cutover.

3.6.1 Requirements Planning

In this phase, the researcher met with the driving school administrator, instructors, and students to gather information about the existing system. The researcher identified the challenges of the manual system and collected the requirements needed for the proposed Online Driving School Management System at AA Driving School, Mombasa. Information was collected through interviews, questionnaires, observation, and review of existing records. The requirements identified included student registration, instructor management, lesson scheduling, vehicle management, fee payment, student progress tracking, and report generation.

Figure 3.1: Requirements Planning Phase of RAD Methodology

The requirements planning phase provided a clear understanding of the problems in the existing system and the needs of the users. The information collected during this phase was used as a basis for designing the proposed system.

3.6.2 User Design

In this phase, the researcher designed the proposed system together with the users. Simple prototypes of important system interfaces, such as student registration forms, payment forms, lesson scheduling pages, student progress pages, and report pages, were created. The administrator, instructors, and students were given an opportunity to review the prototypes and provide their opinions and suggestions. The researcher used the feedback obtained from the users to modify and improve the designs. This process was repeated until the proposed system design met the users' requirement and expectation.

During this phase, the actual system was developed. The researcher created the database, designed the user interfaces, and wrote the program using PHP, MySQL, and XAMPP. The system was tested regularly, and any errors found were corrected before moving to the next phase.

Figure 3.1: Construction Phase of RAD Methodology

XAMPP was used to provide the local server environment for running and testing the system. The system was tested regularly to identify and correct errors. After all, identified errors were corrected and the system was working properly, it was prepared for the next phase of the RAD methodology.

3.6.4 Cutover

The Cutover Phase involved putting the completed Online Driving School Management System into actual use. The system was installed, users were trained, data was transferred, and final testing was carried out to ensure that the system worked correctly.

Online Driving School Management system

Online Driving School Management system

Figure 4.6.1System Architecture diagram of the online Driving school management System.

The system architecture diagram shows how users interact with the Online Driving School Management System at AA driving school, Mombasa through the web interface. The system processes user requests using PHP, communicates with the MySQL database to store and retrieve information, and uses XAMPP as the local server environment. This architecture allows information to flow efficiently between users, the application, and the database.

4.7 Design Techniques

Design techniques are methods used to plan and develop the Driving School Management System. They help the developer understand how the system will work and how the different parts of the system will be connected.

4.7.1 Use Case Diagram

A use case diagram shows the users of the system and the activities they perform. The users are the Administrator, Receptionist, Instructor, and Student. The main activities include logging in, registering students, scheduling lessons, recording payments, viewing driving test results, generating reports, and logging out.

4.7.2 System Flowchart

A system flowchart shows the steps followed by the system when processing information. It starts when a user logs in, performs a task such as registering a student or recording a payment, saves the information in the database, and finally displays the required results.

4.7.3 Entity Relationship Diagram (ERD)

An Entity Relationship Diagram (ERD) shows how the database tables are related. The main tables in the system are Students, Instructors, Lessons, Payments, Driving Test Results, and Users.  ERD helps to organize data correctly and avoid duplication.

4.8 Database Design

Database design is the process of organizing and storing data in a database. It helps to ensure that information is stored correctly, can be accessed easily, and is protected from loss or duplication. The Driving School Management System uses a database to store information about students, instructors, lessons, payments, driving test results, and users.
